# Contributing to Shadow Auditor

Shadow Auditor is source-available and is not open source. The
[license](LICENSE) permits use of unmodified copies but does not permit code
modification, derivative works, or redistribution without prior written
permission from the copyright holder.

## Welcome contributions

The following are welcome:

- bug reports, feature requests, and reproducible examples through
  [GitHub Issues](https://github.com/Yahya-hacker/shadow-auditor/issues);
- private vulnerability reports under [SECURITY.md](SECURITY.md);
- documentation corrections and clarifications; and
- feedback about supported workflows and compatibility.

Search existing issues before opening a new one. Keep examples minimal and
remove credentials, proprietary code, and target data.

## Documentation-only pull requests

The copyright holder grants permission to prepare and submit
documentation-only changes to this repository solely for review through a
GitHub pull request. This permission does not allow republishing the
documentation or distributing a modified copy of Shadow Auditor elsewhere.

Keep documentation changes focused, explain the user-visible correction, and
run any documentation checks already present in the repository.

## Code changes require permission

Do not submit source, test, build, dependency, or workflow modifications unless
the copyright holder has first authorized that work in writing. Opening an
issue, receiving an issue assignment, or creating a fork is not by itself
permission to modify the software.

If code work is authorized, follow the scope and contribution terms in that
written permission. The project may require additional contributor terms
before accepting the change.

## Review and conduct

All submissions are reviewed by the repository owner. Be respectful,
constructive, and lawful. Submission does not guarantee acceptance or a
release timeline.
